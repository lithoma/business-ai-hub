## 视觉和操作

- 参考 Haleon 官网：本地品牌标识、黑白中性色、少量鲜绿色主操作；文字不使用低对比的绿色配白色。
- 不依赖外网字体或图片服务。品牌资产来源见 `frontend/public/brand/SOURCE.md`。
- 保留“AI 分析 / 我的任务 / 分析报告”导航；草稿、启用、暂停用文字和状态色区分。
- 统一字号、行距、表单、按钮、报告卡片；时间仍只在前端显示整点选项。
- 首屏直接显示输入区；跟随新消息只滚动对话内部，不把整个页面拉到底部。
- 桌面保留右侧可滚动流程；窄屏优先展示提问区，流程移到后面，示例问题横向浏览。
- 创建任务表单按执行计划、触发条件、报告与发送分段；当前底层业务配置不因样式变化而改变。
