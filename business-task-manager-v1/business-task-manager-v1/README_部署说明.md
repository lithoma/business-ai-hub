# Task Manager — 当前集成说明（2026-10-21）

业务调用统一 `genie_one`。不配置 A1/A2 Space ID，也不使用 Supervisor。
轻量模型负责对话分流与任务信息提取；Genie One 负责业务分析、触发 SQL
生成、定性判断与报告。审核保存的 SQL 后续直接执行，不重复调用模型生成。

当前选定部署目标是**公司内网服务器**。完整配置与操作步骤见
[Hub 部署说明](../../business-ai-hub/README-DEPLOY.md)。运行时配置、任务 SQL、
提示词与模板均从本 Git 读取，不依赖旧个人 Workspace 文件路径。

- `execution.enabled` 保持 `false`；没有启动 Job 或调度。
- 任务/报告含服务端绑定的创建者身份，不能通过编辑负责人切换数据权限。
- 后台运行必须显式注入 `CreatorRunner`，由公司批准的凭据代理返回创建者
  的有效用户身份。缺失或不匹配时，在业务查询之前停止。
- 不使用共享 Spark/Job 身份代替创建者查询业务数据。
- SQL 条件返回严格 BOOLEAN；false 不生成报告、不发送报告邮件；无法判断时报错。
- 邮件需要独立发件授权；自动发送保持关闭。创建者权限的 CSV 导出还需接入
  同身份执行适配器，不能使用元数据存储身份读取业务附件数据。

`main.py` 保留旧 Databricks Job 入口作为兼容代码，不是内网服务器的部署入口。
旧 Job、Alert 与旧应用源码已放入 `migration/` 作为参考；不能原样导入并启用。
已有 SQL Alert 发送路径只用于维护历史兼容，不是新项目的推荐邮件通道。
